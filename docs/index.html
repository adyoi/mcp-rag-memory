Who is this for?

The Coder — "I'm The Coder, Selamat datang dan Semoga perjalanan mu menyenangkan"
Stored as an importance-1.0 memory with tag identity. Every session recalls it on start.

What it does

🧠
Context Memory

Remember facts, decisions, preferences. Recall them later. Rate by importance. Consolidate duplicates.

📚
Document RAG

Ingest docs (text, files, folders) → chunk → embed locally → store in SQLite → semantically retrieve.

⚡
Zero APIs

1024-dim local hashing embedder, built-in node:sqlite. Fully offline. No API keys needed.

🔌
Universal MCP

Standard MCP server — works with opencode, Claude Desktop, Cursor, VS Code and any MCP client.

Architecture

database.ts
node:sqlite — documents, chunks, memories
embedder.ts
1024-dim local hashing (FNV-1a + n-grams)
chunker.ts
Paragraph/code-aware chunking with overlap
vector-search.ts
Cosine similarity brute-force
pipeline.ts
Ingest / search / retrieve / document mgmt
memory.ts
Remember / recall / consolidate / stats
rag-server.ts
MCP server — 18 tools, stdio transport

Data lives in .rag-data/rag.sqlite (git-ignored).

Configuration

opencode (global)

{
  "mcp": {
    "rag-memory": {
      "type": "local",
      "command": ["node", "--import", "tsx", "src/mcp/rag-server.ts"],
      "cwd": "D:/Project/mcp-server",
      "environment": { "RAG_DB_DIR": "D:/Project/mcp-server/.rag-data" }
    }
  }
}

Claude Desktop

{
  "mcpServers": {
    "rag-memory": {
      "command": "node",
      "args": ["--import", "tsx", "D:/Project/mcp-server/src/mcp/rag-server.ts"],
      "env": { "RAG_DB_DIR": "D:/Project/mcp-server/.rag-data" }
    }
  }
}
