💾Input sesi tersimpan otomatis

Setiap pesan yang kamu ketik di opencode bisa ikut masuk store RAG sebagai dokumen yang bisa dicari — tanpa mencampur memori jangka panjang yang kurasi.

# plugin ".opencode/plugin/session-logger.ts" auto-sync tiap menit (RAG_AUTOSYNC=0 utk matikan)
npm run sync-latest -- --dir "D:/Project/my-app"   # sesi terbaru di workspace itu
npm run sync-session -- ses_abc123                  # sesi tertentu
npm run cli -- sessions                             # daftar sesi terbuka

Data dibaca dari DB opencode sendiri (~/.local/share/opencode/opencode.db), aman karena dedup SHA-256 — jalan berulang-ulang tidak bikin dobel. Input panjang otomatis dipadatkan ke point inti (ekstraktif, tanpa LLM) supaya storage ramping; ketik ulang tetap utuh. Tool MCP rag_sync_session nyediain akses yang sama lewat MCP.

🏗️Arsitektur

database.ts
node:sqlite — dok, chunk, memori, chunks_fts, meta
transcript.ts
Baca sesi opencode (DB global+local) — sinkron input ke store
embedder.ts
Hash lokal 1024-dim (FNV-1a + n-gram)
embeddings.ts
Lapisan provider: local | transformers (opsional)
chunker.ts
Chunking sadar paragraf/kode + overlap
vector-search.ts
Cache vektor + FTS5 BM25 + gabung RRF
pipeline.ts
Ingest async / dedup / guard / kelola dok
memory.ts
Remember / recall (decay) / consolidate / prune
rag-server.ts
Server MCP — 19 tools, transport stdio

🍪 Data tersimpan di .rag-data/rag.sqlite (di-gitignore, memori tidak pernah ter-push!)

🎛️Konfigurasi

🔥 opencode (global)

{
  "mcp": {
    "rag-memory": {
      "type": "local",
      "command": ["node", "--import", "tsx", "src/mcp/rag-server.ts"],
      "cwd": "D:/Project/mcp-server",
      "environment": { "RAG_DB_DIR": "D:/Project/mcp-server/.rag-data" }
    }
  }
}

🟣 Claude Desktop

{
  "mcpServers": {
    "rag-memory": {
      "command": "node",
      "args": ["--import", "tsx", "D:/Project/mcp-server/src/mcp/rag-server.ts"],
      "env": { "RAG_DB_DIR": "D:/Project/mcp-server/.rag-data" }
    }
  }
}
