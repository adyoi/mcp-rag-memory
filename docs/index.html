✨ What it does

🧠
Context Memory

Remember facts, decisions, preferences. Recall them later. Rate importance, squash duplicates!

📚
Document RAG

Feed it docs → it chunks, embeds & stores in SQLite → ask questions, get the right bits back.

⚡
Zero APIs

1024-dim local hashing embedder, built-in node:sqlite. No cloud, no keys, no bill 💸

🔌
Universal MCP

Works with opencode, Claude Desktop, Cursor, VS Code — every MCP buddy, one memory.

🏗️ Architecture

database.ts
node:sqlite — docs, chunks, memories
embedder.ts
1024-dim local hashing (FNV-1a + n-grams)
chunker.ts
Paragraph/code-aware chunking w/ overlap
vector-search.ts
Cosine similarity brute-force
pipeline.ts
Ingest / search / retrieve / doc mgmt
memory.ts
Remember / recall / consolidate / stats
rag-server.ts
MCP server — 18 tools, stdio transport

🍪 Data lives in .rag-data/rag.sqlite (git-ignored, never pushes your memories!).

🎛️ Configuration

🔥 opencode (global)

{
  "mcp": {
    "rag-memory": {
      "type": "local",
      "command": ["node", "--import", "tsx", "src/mcp/rag-server.ts"],
      "cwd": "D:/Project/mcp-server",
      "environment": { "RAG_DB_DIR": "D:/Project/mcp-server/.rag-data" }
    }
  }
}

🟣 Claude Desktop

{
  "mcpServers": {
    "rag-memory": {
      "command": "node",
      "args": ["--import", "tsx", "D:/Project/mcp-server/src/mcp/rag-server.ts"],
      "env": { "RAG_DB_DIR": "D:/Project/mcp-server/.rag-data" }
    }
  }
}
