RAG + Context Management MCP Server

Persistent long-term memory & knowledge retrieval for opencode

Node.js TypeScript node:sqlite 18 MCP tools Offline

Identity

The Coder — "I'm The Coder, Selamat datang dan Semoga perjalanan mu menyenangkan"
Stored as an importance-1.0 memory with tag identity; every opencode session recalls it on start.

What it does

  • RAG — ingest documents (text / files / folders), chunk + embed locally, store in SQLite, semantically retrieve context.
  • Context Management — remember facts/decisions/preferences, recall them, rate by importance, consolidate duplicates, filter by type/tag.
  • Zero external APIs — local hashing embedder (1024-dim), built-in node:sqlite, fully offline.
  • MCP server — runs on stdio, exposed as mcp.rag-memory in opencode.

Quick start

Architecture

src/
├── db/database.ts          node:sqlite (documents, chunks, memories)
├── rag/
│   ├── embedder.ts         local hashing embedder (1024-d, FNV-1a)
│   ├── chunker.ts          paragraph/code-aware chunking
│   ├── vector-search.ts    cosine similarity brute-force
│   └── pipeline.ts         ingest / search / retrieve
├── memory/memory.ts        remember / recall / consolidate
├── mcp/rag-server.ts       MCP server (18 tools, stdio)
├── cli.ts                  CLI playground
└── test/test-all.ts        full test suite

Configuration

The MCP server is registered globally (~/.config/opencode/opencode.json) so it works in every project:

{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "rag-memory": {
      "type": "local",
      "command": ["node", "--import", "tsx", "src/mcp/rag-server.ts"],
      "cwd": "D:/Project/mcp-server",
      "enabled": true,
      "environment": { "RAG_DB_DIR": "D:/Project/mcp-server/.rag-data" }
    }
  }
}

Notifications + sound are enabled via ~/.config/opencode/tui.json (attention).

Workflow

  1. Save knowledge: rag_ingest_text / rag_ingest_file / rag_ingest_dir
  2. Persist decisions: memory_remember
  3. Prepare a prompt: memory_context + rag_retrieve, inject, send to the LLM.
